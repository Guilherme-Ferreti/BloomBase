# BloomBase

## Project Overview

BloomBase is an educational website designed to make information about common flowers easy to access for everyone. The website is aimed at casual flower enthusiasts who want to learn more about flowers through a clean, modern, and easy-to-understand interface.

The project's goal is to provide reliable information about flowers without overwhelming visitors with technical botanical terminology. Every page should balance formal, trustworthy content with a visually appealing, nature-inspired design.

Content is generated with the assistance of AI and reviewed by human administrators before being published, ensuring both efficiency and accuracy.

---

# Target Audience

The website is intended for:

* Casual flower lovers
* People looking up information about a specific flower
* Anyone interested in learning more about common flowers

No user accounts are required, and all content is freely accessible.

---

# Main Features

The website includes the following core features:

* Search flowers by their common or scientific name
* Browse the complete flower collection
* View detailed information pages for each flower
* Browse flowers by category

The search system should support partial matches, allowing visitors to find flowers even if they only know part of the name.

---

# Flower Information

Each flower has its own dedicated page containing the most relevant information, including:

* Common name
* Scientific name
* Image gallery
* Description
* Interesting facts
* Botanical family
* Lifespan
* Care instructions

Images are sourced from Wikimedia Commons, and each flower may contain multiple images.

---

# Categories

Visitors should be able to browse flowers by:

* Botanical family
* Climate
* Flowering season

These categories provide alternative ways to discover flowers beyond the search feature.

---

# Website Pages

## Home

The landing page introduces the project and provides quick access to the search feature and flower collection.

## Browse Flowers

A page displaying all available flowers, allowing visitors to explore the collection.

## Flower Details

A dedicated page for each flower containing its images and educational information.

## Category Pages

Pages listing flowers that belong to a selected family, climate, or season.

---

# Content Management

The website content is managed exclusively by administrators.

Administrators are responsible for:

* Adding new flowers
* Editing existing information
* Reviewing AI-generated content before publication
* Managing flower images

Visitors cannot contribute or edit content.

---

# Design Goals

The website should have a visual identity that is:

* Modern
* Botanical
* Clean
* Formal
* Easy to understand
* Accessible

The interface should prioritize readability and make information easy to find.

---

# Accessibility

Accessibility is an important goal of the project.

The website should be designed to work well with screen readers and present information in a clear, semantic, and accessible way.

---

# Responsive Design

The website should provide a good experience across desktop computers, tablets, and mobile devices.

---

# Technology

The project will be built using:

* Laravel
* Livewire
* Alpine.js
* Tailwind CSS

The administration dashboard will be built using Filament PHP.

---

# Project Goals

The primary objectives of BloomBase are:

* Provide reliable and easy-to-understand information about common flowers.
* Make flower information easy to discover through search and browsing.
* Present educational content in a modern, visually appealing interface.
* Maintain a simple and maintainable codebase.
* Ensure all published content is reviewed by human administrators before becoming publicly available.
